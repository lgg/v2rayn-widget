# 0012 - Cross-Platform Feasibility Report

## Result

Deferred. Repository audit confirms that current process, UI automation, privilege, window, installer and runtime-control paths are Windows-specific. No validated Linux/macOS target-client contract or real-system evidence exists.

## Decision

Do not implement or advertise Linux/macOS support until the reopening conditions in the matching decision are met.
